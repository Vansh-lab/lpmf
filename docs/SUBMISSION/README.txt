LPMF — Load Profile Management & Forecasting
Final submission package
=============================================

This folder contains only the final files for submission/printing. Working
files, drafts, screenshots and source assets live elsewhere in docs/ and
are not part of this package.

LPMF_Project_Report.docx / .pdf
    The main project report (13 pages): cover, acknowledgement, supervisor
    certificate, abstract, contents, chapters 1-10, references. Submit the
    .pdf for printing/upload; the .docx is kept in case the examiner or
    department needs an editable copy.

LPMF_Project_Presentation.pptx
    The viva/defence slide deck (15 slides): title, problem statement,
    gap & USP, dashboard overview, dataset & variables, model accuracy,
    six feature-pair slides covering all 12 dashboard pages, benchmarks,
    references, thank you.

LPMF_Presentation_Script.docx / .pdf
    Slide-by-slide speaker notes (Hinglish) matching the 15-slide deck:
    what to say for each slide (~20 minutes total), formulas, worked
    examples, and a 19-question viva Q&A appendix. For the presenter's
    own use during rehearsal and the viva — not for submission to
    examiners unless asked.

Not included here (see docs/ directly if needed):
    - docs/demo_backup_screenshots/  — one screenshot per dashboard page,
      for use if the live demo or internet fails during the viva.
    - docs/README_DEMO.md            — how to start the app, log in, and
      recover if something crashes during the demo.
